# Programación Orientada a Objetos (POO)

La Programación Orientada a Objetos (POO) es un paradigma de desarrollo que organiza el software utilizando objetos. Un objeto representa una entidad que combina datos y comportamientos dentro de una misma estructura.

La POO facilita la creación de aplicaciones más organizadas, reutilizables y fáciles de mantener, especialmente en proyectos grandes.

Los conceptos fundamentales de la programación orientada a objetos son:

* **Clase**: plantilla que define las propiedades y métodos que tendrán los objetos.
* **Objeto**: instancia concreta creada a partir de una clase.
* **Atributos**: variables que almacenan el estado de un objeto.
* **Métodos**: funciones asociadas a un objeto que definen su comportamiento.

Además, la POO se basa en varios principios importantes:

* **Encapsulación**: protege los datos internos del objeto y controla su acceso.
* **Herencia**: permite crear nuevas clases reutilizando características de otras clases.
* **Polimorfismo**: posibilita que diferentes objetos respondan de manera distinta al mismo método.
* **Abstracción**: simplifica el diseño mostrando únicamente los elementos necesarios.
